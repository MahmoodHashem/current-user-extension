
# Privacy Policy

Last updated: July 2026

GitHub Account Guard & Identity respects your privacy.

## Data Collection

This extension does not collect, store, transmit, or sell any personal information.

## Local Storage

The extension may use the browser's local storage solely to save user preferences and settings. This information remains on your device and is never transmitted to any external server.

## GitHub Access

The extension runs only on GitHub pages to provide account identity indicators and related functionality. It reads page content locally within your browser and does not send GitHub account information to any external service.

## Third-Party Services

This extension does not use analytics, advertising, tracking services, or remote code.

## Contact

For questions or issues, please open an issue on the project's GitHub repository.
